# Human Activity Recognition Using Machine Learning

## Project Overview

Human Activity Recognition (HAR) is a machine learning project that focuses on identifying and classifying human physical activities using sensor-based data.

This project implements supervised and unsupervised machine learning algorithms to analyze activity data, perform classification, discover patterns and evaluate model performance.

The project explores different machine learning techniques and compares their performance in recognizing human activities.

## Objectives

- To understand and explore the Human Activity Recognition dataset.
- To perform Exploratory Data Analysis (EDA).
- To implement supervised machine learning classification algorithms.
- To implement unsupervised learning using K-Means clustering.
- To evaluate and compare model performance using appropriate evaluation metrics.
- To visualize data patterns and clustering results.

## Dataset Description

The project uses training and testing datasets containing extracted features and corresponding activity labels.

| Dataset File | Description |
|---|---|
| X_train.txt | Training feature dataset |
| y_train.txt | Training activity labels |
| X_test.txt | Testing feature dataset |
| y_test.txt | Actual testing activity labels |

## Project Methodology

The project is divided into four major stages:

1. Data Collection and Exploratory Data Analysis
2. Supervised Learning – Classification
3. Random Forest Model Development and Evaluation
4. Unsupervised Learning – Clustering

## Machine Learning Algorithms Used

### 1. K-Nearest Neighbors (KNN)

KNN is a supervised learning algorithm used to classify activities based on the similarity between data points.

### 2. Decision Tree

Decision Tree is a supervised learning algorithm that makes predictions using a tree-like structure of decision rules.

### 3. Random Forest

Random Forest is an ensemble learning algorithm that combines multiple decision trees to improve classification performance.

### 4. K-Means Clustering

K-Means is an unsupervised learning algorithm used to group similar data points into clusters.

## Model Evaluation Techniques

The following evaluation techniques are used:

- Accuracy Score
- Confusion Matrix
- Classification Report
- Feature Importance
- Elbow Method
- Silhouette Score
- Adjusted Rand Index (ARI)
- Normalized Mutual Information (NMI)
- Principal Component Analysis (PCA) Visualization
